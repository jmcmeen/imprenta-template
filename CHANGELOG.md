# Changelog

Template releases carry the number of the imprenta release they are set up
for. Each entry lists what a repo made from an earlier release has to change
to move to this one, beyond bumping the pin.

## 0.1.0

First release, for imprenta 0.1.0: a catalog, lorem ipsum content with term
tables, a theme (`leaflet` and `volume`), the Makefile and a check workflow.
